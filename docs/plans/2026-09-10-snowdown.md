# Snowdown: High Noon, Low Temperatures

## Scope

Playable browser demo: two cowboys cooperatively fight snowman outlaws in a procedural 3D snowy western town. Fixed elevated Diablo-style orthographic shared view. Whimsical frontier art, distinct player colors, readable non-blocking HUD.

## Acceptance

- Two independent local players: WASD/F/G and arrows/K/L; standard gamepad input.
- Snowball collision, hostile snowballs, dodge, three waves, scoring, cocoa healing, teammate revival, win/lose/restart and optional solo.
- Real WebGL visuals served from local Three.js, no remote dependencies.
- Pause/blur safety and deterministic test-only mutation hooks; production read-only state snapshot.
- Arcade registration and reachable protected homelab preview.
- Browser regression and CI-equivalent tests, Python regression tests, independent spec and quality review.
- Visually inspected screenshot and real-input co-op gameplay video.

## Lanes

Builder: game UI/world/combat and first tests. Research/media: conventions, UX and showcase advice. Merquery: integration, independent gamepad tests, capture, verification, artifacts and explicit-path commit. Performance specialist: investigate headless rendering slowdown, optimize without altering combat. Reviewers: independent spec and quality gates.

## Verification commands

- `KANBAN_MODE=fixture npm test`
- `KANBAN_MODE=fixture CI=true npm run test:ci`
- `uv run pytest`
- `ARTIFACT_VIDEO_MS=10000 npm run artifacts:video -- snowdown`
- Check local route, existing public auth redirect, and private path denial.

Concurrent tests must use distinct preview ports AND distinct Playwright output directories. Generated screenshot/video/test outputs stay ignored. Commit only this change set; preserve unrelated files.

## Approved polish pass (item 1 only)

- Preserve renderer batching, matte lighting, static shadow bake and adaptive resolution. Replace slow-frame simulation clipping with bounded fixed-size substeps and verify collision/time correctness; do not claim a higher rendered FPS from a timing fix.
- Screen-relative keyboard and controller movement: projected up/right behave as screen directions.
- Controller Start uses rising-edge pause/resume even while simulation is paused; held buttons never repeatedly toggle.
- Readable throw windup/release, hit/recoil and dodge-ready feedback, with player identity markers and native-resolution HUD.
- Verify each player's actual actions independently, complete all release tests, review, screenshot and real-input video capture.
- Human two-person physical-controller/keyboard-rollover playtest remains explicitly pending. Checklist: `docs/plans/snowdown-couch-playtest.md`.

## Non-goals

Online networking, mobile touch controls, external art assets, changing existing access protection, or claiming physical-controller testing without hardware.
